## 1. Objetivo do seguinte Trabalho Prático:

Desenvolver uma biblioteca, juntamente com um sistema de documentação e compilação (na forma estática e dinâmica), voltada para a área de _Machine Learning_. Tal artefato conterá, a princípio, funções como KNN (_K-Nearest Neighbours_), MSE (_Mean Squared Error_), entre outras técnicas, além de contar com rotinas de E/S. Para interagir com a aplicação, o usuário terá acesso a uma CLI (_command line interface_).

## 2. Divisão dos 4 módulos funcionais:

A princípio, foi estipulada a seguinte divisão dos módulos de acordo com suas funcionalidades:

- **Entrada/Saída e Padronização**
> Funções relacionadas com o recebimento, tratamento e saída de informações e dados por parte do programa.

- **KNN**
> Funções relacionadas ao cálculo desta técnica de ML

- **MSE**
> Funções relacionadas ao cálculo desta técnica de ML

- **CLI**
